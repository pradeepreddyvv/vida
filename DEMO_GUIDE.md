# Vida judge walkthrough

Open https://dahb851px2bik.cloudfront.net/test and choose **Try Vida with sample data**. Each visitor gets an isolated 24-hour workspace with fictional content.

1. Explore tasks, habits, notes, and sample commitments.
2. In Ask Vida, choose **Try organizing my Saturday**. The editable starter fills the next Saturday date and sample destinations.
3. Send it. Review two tasks, one shopping note, one sample Notion append, and one sample calendar event. No requested changes run yet.
4. Approve the ready steps. See **5 changes completed**, expandable details, and result links.
5. Refresh: saved results remain. Ask **“What’s on my shopping list?”** to retrieve saved context.

The sample event and Notion page are local simulations, explicitly marked demo only/not synced. Start a separate empty personal workspace to use real integrations; sample data does not carry over.

See [JUDGE_EVIDENCE.md](JUDGE_EVIDENCE.md) for verified checks, screenshots, architecture, and limitations. Do not present sample screenshots as proof of external Google/Notion writes.
